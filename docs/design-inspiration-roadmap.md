## 一、设计灵感

### 1. 品牌 & 视觉方向（避开命名禁忌：无水果/奇幻/中二 slogan）

| 灵感源 | 借鉴点 | 落地到 ThresholdEcho |
|:--|:--|:--|
| Windows 11 Fluent | 圆角卡片、亚克力半透明、柔和阴影 | 主界面「毛玻璃卡片流」，扫描时背景光晕微动 |
| Raycast / uTools | 极简命令框、克制配色 | 主入口做成「⌘ 呼出式命令面板」，一切功能可打字直达 |
| 1Password | 安全感 + 精致动效 | 「健康分」做成精致仪表盘，而非粗糙进度条 |
| Notion 数据看板 | 模块化信息密度 | 每项功能一卡片，可拖拽排序/折叠 |
| VS Code 状态栏 | 常驻轻量信息 | 托盘图标实时显示 CPU/内存/温度，悬停出气泡 |

### Phase 4：点击即问（第 1-2 周）

| # | 任务 | 功能描述 | 技术要点 | 优先级 | 工时 |
|:--:|:--|:--|:--|:--:|:--:|
| 4.1 | `call_agent()` 通用函数 | 数据快照→拼 Prompt→调 agent CLI→返回人话 | subprocess 调 `openclaw agent --json`，CREATE_NO_WINDOW | 🥇 | 1h |
| 4.2 | `explain-process` API | 点击进程 → 身份/子服务/安全评级 | 收集 PID/CPU/内存/网络连接 | 🥇 | 1.5h |
| 4.3 | `explain-software` API | 点击软件 → 用途/必要性/可卸载性 | 注册表 Uninstall 键 + 安装日期 | 🥈 | 1h |
| 4.4 | `explain-startup` API | 点击启动项 → 耗时/禁用后果 | 启动项注册表 + 耗时估算 | 🥈 | 1h |
| 4.5 | `explain-device` API | 点击设备 → 驱动时效/bug/更新建议 | WMI 驱动列表 | 🥉 | 1h |
| 4.6 | `explain-junk` API | 点击垃圾类别 → 溯源 + 副作用 | 扫描结果 JSON 直接喂 | 🥈 | 1h |
| 4.7 | `explain-error` API | 点击事件日志 → 人话翻译 | EventLog 读取 + ID 统计 | 🥉 | 1.5h |
| 4.8 | 前端气泡组件 | 表格行可点击 + 加载态 + 气泡渲染 | CSS/JS 组件，data-* 属性绑定 | 🥇 | 2h |
| 4.9 | 开机自检报告 | 启动耗时/变慢归因/异常告警 | 启动事件采集 + 昨日对比 | 🥈 | 1h |
| 4.10 | 游戏模式联动 | 检测游戏进程 → 暂停更新/高性能/结束后恢复 | 进程监听 + 设置快照/回滚 | 🥉 | 2h |
| 4.11 | 修复对比动画 | 修复前后分数/空间/速度对比展示 | 修复前快照 + 修复后 diff | 🥈 | 1h |

### 关键风险与对策

| 风险 | 影响 | 对策 |
|:--|:--|:--|
| agent CLI 调用延迟（60s 超时） | 气泡等待久 | loading 动画 + 缓存热门解释 + 可取消 |
| 每次点击都花 API token | 成本上升 | 本地规则引擎兜底常见项，Agent 只处理复杂项 |
| 权限不足拿不到驱动/日志 | 部分功能阉割 | 管理员模式提示 + 降级方案 |
| 破坏性操作误触 | 系统风险 | 写操作二次确认 + 操作前快照可回滚 |
