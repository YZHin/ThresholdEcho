# Agent 思维 × PC Manager 深度联动设计方案

> 作者：小柚子 🍊 | 日期：2026-08-01 | 版本：v1.0
>
> **核心命题**：如何让 OpenClaw AI Agent 与 PC Manager 有机联动，实现「点击即问、智能扫描、主动代理」的 Agent 型电脑管家。

---

## 🏗️ 三层 Agent 集成架构

```
┌─────────────────────────────────────────────────────────┐
│  Layer 3: Autonomous Agent（自主代理层）                  │
│  主动巡检 / 异常预警 / 行为学习 / 跨数据源推理            │
├─────────────────────────────────────────────────────────┤
│  Layer 2: Contextual Agent（上下文代理层）                │
│  点击即问 / 智能归因 / 自然语言查询 / 知识关联            │
├─────────────────────────────────────────────────────────┤
│  Layer 1: Rule Engine（规则引擎层）— ✅ 当前已有          │
│  静态扫描 / 固定阈值 / 预设清理路径                       │
└─────────────────────────────────────────────────────────┘
```

现有 PC Manager v2.0 在 Layer 1（规则引擎层）已经成熟：静态扫描、健康评分、垃圾清理、一键修复都跑通了。本文重点设计 **Layer 2 + Layer 3** 的 Agent 化改造。

## 🧠 「Agent 思维」vs「规则思维」核心差异

| 维度 | 传统规则引擎 | Agent 思维 |
|:--|:--|:--|
| **数据处理** | 单源提取 → 显示 | 多源融合 → 关联推理 → 生成洞察 |
| **用户交互** | 列表/表格，用户自己读 | 自然语言对话，Agent 替你读 + 替你总结 |
| **问题诊断** | 给你看指标数据 | 告诉你「为什么」+「有多严重」+「怎么做」 |
| **异常发现** | 阈值触发报警 | 时间序列分析 + 模式识别 + 预测 |
| **知识边界** | 预设规则覆盖的路径 | 可联网查询 + CVE/bug 数据库 + 社区经验 |
| **输出质量** | 「C 盘已用 78%」 | 「C 盘 2 个月后会满，因为微信聊天记录月增 15GB，建议迁移」 |
| **安全性** | 静态白/黑名单 | 签名链验证 + 行为沙箱推理 + 多引擎情报交叉验证 |
| **个性化** | 无 | 学习你的使用模式、偏好、容忍度 |

## 💡 关键技术架构：Agent API 中间层

所有场景共用一个核心模式——**«数据快照 → Agent Prompt → 推理输出»**：

```
┌──────────┐    ┌──────────────────┐    ┌──────────────┐
│  PC      │───▶│  API: /api/agent │───▶│  OpenClaw     │
│  Manager │    │  /explain?       │    │  Gateway      │
│  UI      │    │    type=process  │    │  (agent CLI)  │
│          │    │    id=1234       │    │               │
│          │◀───│                  │◀───│               │
│  ←气泡   │    │  ← Agent 自然语言 │    │               │
└──────────┘    └──────────────────┘    └──────────────┘
```

### 新增后端 API（在 `server.py` 中实现）

| 端点 | 输入 | Agent 做什么 |
|:--|:--|:--|
| `POST /api/agent/explain-process` | `{pid, name}` | 进程身份识别 + 子服务树 + 安全评级 + 资源历史 |
| `POST /api/agent/explain-software` | `{name, version}` | 软件用途/必要性/替代品/卸载风险评估 |
| `POST /api/agent/explain-device` | `{name, driver_ver}` | 驱动时效性 + 已知 bug + 更新建议 |
| `POST /api/agent/explain-startup` | `{name, impact}` | 启动耗时量化 + 禁用后果 + 使用频率 |
| `POST /api/agent/explain-junk` | `{category, path}` | 垃圾溯源 + 安全性判定 + 副作用说明 |
| `POST /api/agent/explain-error` | `{event_id, source}` | 自然语言翻译 + 严重程度 + 修复方案 |
| `POST /api/agent/analyze-trend` | `{metric, days}` | 趋势预测 + 异常检测 + 建议 |
| `POST /api/agent/startup-report` | 系统启动事件 | 开机耗时分析 + 变慢归因 + 异常告警 |
| `POST /api/agent/root-cause` | `{symptom}` | 多维数据交叉 → 根因假设 + 验证建议 |

### 统一 Agent 调用流程

```python
# server.py 新增通用函数
def call_agent(prompt_type: str, context: dict) -> str:
    """统一 Agent 调用入口"""
    # 1. 构建 prompt —— 注入系统数据 + 用户上下文
    system_prompt = f"""你是一个专业的 Windows 系统分析师。
当前系统信息：{json.dumps(context, ensure_ascii=False)}
请用自然、有帮助的语气回答。"""

    # 2. 调 openclaw agent CLI
    result = subprocess.run(
        [OC_CLI, "agent", "--message", system_prompt,
         "--json", "--timeout", "60"],
        capture_output=True, text=True,
        creationflags=CREATE_NO_WINDOW
    )

    # 3. 解析并返回自然语言结果
    return json.loads(result.stdout)["reply"]

# 每个 explain 端点都是 call_agent 的薄封装
@app.route("/api/agent/explain-process", methods=["POST"])
def agent_explain_process():
    pid = request.json["pid"]
    # 收集进程上下文：进程名、CPU、内存、子服务、网络连接...
    proc_ctx = _gather_process_context(pid)
    reply = call_agent("explain-process", proc_ctx)
    return jsonify({"reply": reply})
```

### 前端交互模式

```javascript
// 给表格行加点击 → Agent 解释
function makeClickable(element, agentType, contextId) {
    element.style.cursor = 'pointer';
    element.addEventListener('click', async () => {
        // 显示加载气泡
        showAgentBubble('loading', element);

        // 调后端 Agent API
        const res = await fetch(`/api/agent/explain-${agentType}`, {
            method: 'POST',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({id: contextId})
        });
        const data = await res.json();

        // 在 UI 中渲染 Agent 气泡
        showAgentBubble('reply', element, data.reply);
    });
}

// 应用：所有进程名、软件名、设备名都变成可点击的
document.querySelectorAll('.proc-name').forEach(el => {
    makeClickable(el, 'process', el.dataset.pid);
});
```

| 学习能力 | 无 | 记录用户偏好，建议越来越精准 |
| 安全审计 | 只检测 Defender 状态 | 软件签名验证 + 病毒情报 + 防火墙日志分析 |

**核心理念**：传统 PC Manager 是「给你看数据」，Agent 型 PC Manager 是「替你读数据 + 帮你做决策」。每一条数据都变成 Agent 的推理素材，每一次点击都触发一次智能对话。
